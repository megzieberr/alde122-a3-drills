# ALDE122 semester test drills

Three practice drills for the ALDE 122 semester test: argument structure, reading charts (Lesson 9), and referencing and cohesion.
Open `index.html` (or the GitHub Pages link) and pick a drill.
All sources, texts and data in the drills are invented for practice.
Scores are not saved on this site, so note yours down when you finish.
